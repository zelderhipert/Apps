# Apps

Coleção de aplicativos e utilitários pessoais.

## Aplicativos

- **[Opening Lab](./opening-lab/)** — simulador de mãos iniciais de Magic: The Gathering Commander, com critérios personalizados de keep, mulligan e estatísticas.

## Estrutura

```
Apps/
├── index.html            # página inicial da coleção
└── opening-lab/
    ├── index.html        # aplicativo (HTML único)
    └── README.md         # documentação
```

Cada novo aplicativo pode ocupar uma pasta independente, como `nome-do-app/index.html`.

## GitHub Pages

Para publicar esta coleção na web, acesse **Settings → Pages** e escolha **Deploy from a branch**, branch `main`, pasta `/(root)`. A URL planejada é `https://zelderhipert.github.io/Apps/`, com o simulador em `https://zelderhipert.github.io/Apps/opening-lab/`.

**Atenção:** este repositório foi criado como **privado**. GitHub Pages em repositórios privados depende do plano do GitHub; na modalidade gratuita, é necessário tornar o repositório público. A publicação do código e a configuração do Pages são decisões distintas.
